## 🚀 Proyectos destacados

### 1. Sistema de Asistencia Institucional
Sistema web interno desarrollado para administrar marcaciones de asistencia mediante importación de archivos CSV, cálculo automatizado de tardanzas y generación de reportes.
* **Tecnologías:** PHP, JavaScript, MySQL, phpMyAdmin.
* *Proyecto institucional en producción.*

### 2. Respawn Store
Tienda web de consolas y accesorios de videojuegos con catálogo interactivo, diseño responsive adaptado a móviles y control de versiones.
* **Tecnologías:** HTML5, CSS3, JavaScript, Bootstrap.
* **Repositorio:** [github.com/MoshTC/respawn-store](https://github.com/MoshTC/respawn-store)

### 3. Sistema de Matrícula y Alumnos
Aplicación de escritorio con formularios gráficos para registro, mantenimiento y consulta de datos de alumnos aplicando buenas prácticas de POO.
* **Tecnologías:** Java (Swing), POO, SQL.
* *Proyecto académico.*

## 💻 Cómo probar el proyecto localmente

Este proyecto es 100% estático (no requiere Node.js ni instalar dependencias):

1. Clona el repositorio:
   ```bash
   git clone https://github.com/MoshTC/portafolio-victor.git
   ```
2. Entra a la carpeta y abre `index.html` con doble clic o con la extensión Live Server de VS Code.
